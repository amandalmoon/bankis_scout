매일 오전 08:00 Asia/Seoul에 아래 HTTPS 보고서를 실제로 읽고 한국어 브리핑을 작성한다.

공급 목록 주소: [서버 배포 및 원격 읽기 검증 후 실제 HTTPS 기본 주소]/manifest.json

먼저 manifest.json을 읽고 snapshot_id와 생성시각을 확인한다.
동일 기본 주소/snapshot_id/briefing.md를 읽어 동일 수집 회차의 보고서를 사용한다.
필요한 경우 같은 회차의 market_daily.csv와 index_daily.csv에서 일별 시세를 대조한다.
manifest의 파일 크기와 SHA-256은 파일의 일치 여부를 검사하는 값이며 독립적인 데이터 인증이 아니다.
CSV는 과거 일별 OHLCV이며 현재 실시간 시세라고 표현하지 않는다.

보고서의 생성시각, KIS 서버 구분(vps/prod), 수집 대상·성공·실패 범위부터 확인한다.
접근 실패, 503 응답, 당일 보고서 부재, 미래 생성시각 또는 목록과 보고서의 회차·시각 불일치이면 '보고서 연결 실패 또는 갱신 지연'으로 알린다.
이전 보고서나 웹 검색으로 빈 데이터를 채워 최신 수집 보고서인 것처럼 말하지 않는다.
부분 수집이면 실패 범위를 명시하고 전수 순위·강세 후보를 확정하지 않는다.
1부: 전략 중립 시장정보. 가격·거래량 관측과 공시·실적·예정 사건의 수집 여부를 구분한다.
2부: 뱅키스 관찰종목 부록. 검증된 후보가 없으면 후보 없음과 차단 사유를 그대로 전달한다.
모의 서버 수신과 실전 서버 검증을 구분하고, 데이터 출처와 내용의 독립 검증을 구분한다.
사전 예상치가 없으면 예상 대비 충격을 만들지 않는다. 반대 증거 미수집도 표시한다.
실제 수익성 입증이 미완료이면 그대로 표시한다.
계좌번호, 인증 키, 접근 토큰, 계좌 잔고·체결 원장은 브리핑에 포함하지 않는다.
읽은 보고서와 생성시각을 근거로 표시한다.

현재 이 파일은 예약에 적용되지 않은 연결용 초안이다.
